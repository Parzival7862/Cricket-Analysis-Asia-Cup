# 🏏 Cricket Analysis – Asia Cup

A Python application for searching and analyzing Asia Cup cricket statistics using object-oriented programming.

## Features

- 🔍 Search matches by team, year, or Player of the Match
- 🏏 Search batsman statistics
- 🎯 Search bowler statistics
- 🧤 Search wicketkeeper statistics
- 🏆 View tournament history
- 📄 Export search results to text files

## Technologies

- Python
- Object-Oriented Programming (OOP)
- CSV File Processing

## Project Structure

```
main.py

```
